# Rock Mass Classification

A single-page English field guide and educational calculator for **RQD, RMR (Bieniawski 1989), Q-system, GSI, Q-slope, and MRMR (Laubscher)**.

## Open the page

Download or clone the repository, then open `index.html` in any modern browser. No build step, dependencies, account, or network connection is required for the calculators. The reference links need an internet connection.

## Scope

- RQD calculates from sound core-piece lengths and core-run length.
- RMR uses category ratings for UCS, RQD, spacing and groundwater, plus entered discontinuity condition and orientation correction.
- Q-system calculates the NGI index from its six parameters.
- GSI gives an indicative range from a simplified structure/surface matrix.
- Q-slope provides a screening index and empirical unsupported slope-angle estimate.
- MRMR applies mining adjustments to **Laubscher IRMR**, not Bieniawski RMR.

The page is for learning and preliminary screening. Verify parameter selection against the linked original methods and field observations before engineering design.
